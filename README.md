# web

Repositori de webs de NETSEIN i clients.

## Clients / projectes

- **DiqSolucions/** — Web corporativa de Diq Solucions (consultoria Microsoft Dynamics 365 Business Central). Pàgina única estàtica, trilingüe (CA/ES/EN), amb imatges a `DiqSolucions/assets/`.
- **DiqSolucionsCAT/** — Web de Diq Solucions per a diqsolucions.cat: Director Financer Extern (Fractional CFO). HTML estàtic en català, castellà i anglès, generat amb `node DiqSolucionsCAT/_src/build.js` a partir de `_src/content.js`.

## Publicar amb GitHub Pages

Settings → Pages → Source: `main` → carpeta arrel. Les webs queden a `/DiqSolucions/` i `/DiqSolucionsCAT/`. Per publicar `diqsolucions.cat` amb domini propi caldrà un repositori de Pages independent (un domini personalitzat per repositori).
